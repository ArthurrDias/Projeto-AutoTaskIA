AutoTaskIA

Landing page de uma proposta de sistema de organização e produtividade com recursos de inteligência artificial, desenvolvida como projeto acadêmico na área de Desenvolvimento Web.

📌 Sobre o projeto

O AutoTaskIA é uma proposta de sistema voltado para organização e produtividade, utilizando recursos de inteligência artificial para auxiliar o usuário no gerenciamento de suas tarefas e rotina.

A landing page apresenta a proposta da aplicação, seus principais recursos, público-alvo e uma área de contato.

O projeto foi desenvolvido como atividade acadêmica, com foco na aplicação prática de conceitos de desenvolvimento web, estilização e organização de interfaces.

✨ Recursos apresentados

A proposta do AutoTaskIA inclui:

🤖 Priorização inteligente: análise de urgência e importância das tarefas;
⏰ Reorganização automática: reorganização da rotina em caso de atrasos;
🔔 Notificações inteligentes: lembretes para auxiliar no cumprimento das tarefas;
📊 Relatório de produtividade: acompanhamento do tempo gasto em diferentes tipos de tarefas;
🧠 IA Adaptativa: proposta de adaptação da organização da rotina de acordo com o comportamento do usuário.
🎯 Público-alvo

A proposta é direcionada principalmente para:

Estudantes;

Equipes de tecnologia.
